# Voltage & Valve

**Live site: [https://desolatemartial553.github.io/voltage-and-valve/](https://desolatemartial553.github.io/voltage-and-valve/)**

A demo website for **Voltage & Valve**, a fictional plumbing and electrical firm in Leeds. Not a real business.

- **Design:** Circuit technical
- **Built with:** plain HTML, CSS and JavaScript. No framework, no build step, self-hosted fonts and images.
- **Hosting:** GitHub Pages, served from the `main` branch.

To run it locally, open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
